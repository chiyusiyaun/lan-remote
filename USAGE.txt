LAN Remote Desktop v1.2.0
=========================

两个程序
--------
lan-remote-server   被控端 / 注册中心（Service）
lan-remote-client   主控端（在界面输入 Service IP）

用法
----
【A：Service + 被控】
  lan-remote-server.exe
  界面设置 PIN（保存到 server.json）

【B：主控】
  lan-remote-client.exe
  启动后输入 Service IP（如 192.168.1.10）→ 连接
  在设备列表点 A → 输入 A 的 PIN
  地址会记住，下次启动自动用；顶栏可「更换 Service」

端口
----
  8760  Service 注册口
  8765  控制口

配置文件
--------
  Windows  %APPDATA%\lan-remote\server.json
           %APPDATA%\lan-remote\client.json
  Linux    ~/.config/lan-remote/

防火墙：管理员运行 open-firewall.bat
