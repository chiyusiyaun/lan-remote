LAN Remote v1.2.0
=================
统一端口：TCP 8765
  server  注册 API + 门户 + 控制代理（同一端口）
  client  被控（截屏/键鼠）+ 主控界面

路径
  http://IP:8765/          门户（主控）
  http://IP:8765/server/   管理页
  http://IP:8765/server/api/devices
  http://IP:8765/api/devices

用法
【中心机】
  lan-remote-server.exe
  Service 地址示例: http://中心机IP:8765/server

【各电脑】
  lan-remote-client.exe
  Service IP 填: http://中心机IP:8765/server
  或局域网: 中心机IP:8765

同机测试: client 用 -port 8766，避免与 server 抢 8765

手机: http://中心机IP:8765

后台: Windows 托盘 / -bg；Linux nohup ... -bg
